# Transactions

Observed: the page already states the settled single-source request model. Constructors and wire request bodies omit source; the selective assessor emits five-field facts and suppresses every matching EAV. Its current-value and unique-holder accounting counts physical contributions. Receipt lookup is caller-owned and precedes the shared fresh-assessment pipeline.

Cause: attribution is absent at the request/assessment boundary, while current physical facts were formerly equivalent to logical values. No operation arity change is needed.

Bounded problem: require one explicit EntityRef on every request and preview; resolve through existing issued-id/ident/lookup/tempid rules; stamp all material explicit/generated facts, including the automatic instant; preserve distinct EAVS assertions and global EAV retractions without multiplying logical values or holders.

Approaches: per-operation attribution would duplicate independent transaction context and entangle generated changes with user forms. Storing source on every internal logical delta adds repetition when all deltas share one transaction source. Selected: retain ordinary EAV logical expansion, resolve the request source after ordinary tempid allocation, and stamp source once at the material fact boundary. Schema metadata reconstructed only for projection uses canonical system attribution; it is not emitted transaction data. Reuse existing entity input validation and reference resolution. Wire grammar explicitly advances its version; source remains independent of selected time and expansion.

API: request constructors (key,data,source); preview methods preserve existing semantic argument order, then source, then defaults/limits/options. Source identity hashing belongs to encoding/mod owner and receipt integration belongs to root.

Acceptance: empty transaction attributed timestamp; tempid source established in entity position and missing-only-source tempid rejected; ident/lookup resolution; repeat same EAVS redundant, another source material; multiple contributions preserve one logical cardinality/CAS/unique holder; generated replacement/retraction/composite/schema facts share source; wire roundtrip retains source and rejects old version. Exact-retry-before-resolution requires integration checks with root-owned receipts, and global visibility depends on data/index owners.

Actual changes: request source is required by both owned constructors and native envelope version 7. Pipeline preview APIs and the assessor carry source after existing time arguments. Source is validated, included in reserved-input accounting, and resolved after tempid allocation by the existing ordinary resolver. Normalization reserves source tempid names alongside form names, preventing an anonymous map from accidentally establishing a source-only tempid. Material assertions check EAVS; retractions check global EAV; logical values, unique holders, and the streamed schema cardinality transition deduplicate contributions. All emitted datoms receive the resolved source at material_changes, including the automatic instant, callbacks, composites, and schema/replacement retractions.
