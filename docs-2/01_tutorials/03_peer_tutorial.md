# Peer Tutorial

This tutorial is for users who have completed the
[EDB setup](../00_start_here/01_setup.md), have
[access to the peer library](../00_start_here/02_peer_library.md) in their Rust project, and have built the
[`edb` executable and application example](01_application_workflow.md).

- [Run a transactor](04_run_a_transactor.md)
- [Connect to a database](05_connect_to_a_database.md)
- [Transact schema](06_transact_schema.md)
- [Transact data](07_transact_data.md)
- [Query the data](08_query_the_data.md)
- [See historic data](09_see_historic_data.md)

Follow the [EDN workflow](00_edn_workflow.md) to submit the supplied schema and
people data and run queries from a terminal. Follow the
[native application workflow](01_application_workflow.md#what-the-application-demonstrates)
to use the Rust APIs, retain an immutable database value across an update, and
compare current, as-of and history views.

To try the same data model without PostgreSQL or a running transactor, follow
the [in-memory tutorial](02_in_memory.md).
