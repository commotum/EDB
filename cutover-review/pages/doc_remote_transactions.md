No documentation or implementation gap has been observed.

Decision: retain the aligned page and existing native transport. Reuse native request encoding and the same writer authority for local and remote execution. Acceptance checks are source-bearing fresh TLS submission, exact replay after process restart, fixed captured/offline reads, source lookup withdrawal with hints-independent replay, strict old-wire rejection, bounded verified transport, and phase-only health probes. Parent owns shared implementation integration; the hints worker owns the current hints codec/test changes, which this review leaves untouched.
