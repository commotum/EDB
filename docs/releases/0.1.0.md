# EDB 0.1.0

EDB's first experimental source release includes the native Rust peer library
(`edb_core`) and command-line executable (`edb`). EDB makes source first-class
alongside time, retaining attribution on each assertion and retraction in a
shared database of record.

## Included

- Immutable database values with current, as-of, since, and historical reads.
- Datalog queries, Pull, entity navigation, and EDN schema and transaction data.
- Atomic transactions with one explicit source, exact retries, and source-first indexes.
- PostgreSQL-backed storage and transactor operation, backup/restore, offline
  backup reads, fulltext search, and excision.
- MIT licensing and automated formatting, lint, documentation, ordinary and
  live integration tests, and optimized CLI checks.

## Install from source

The verified platform is x86-64 Linux, using Rust 1.90.0 and PostgreSQL 15.
Rust and Cargo 1.90 or newer are supported. Install a native linker, OpenSSL
development headers, and `pkg-config` before building:

```sh
git clone https://github.com/commotum/EDB.git
cd EDB
git checkout v0.1.0
cargo build --locked --release --lib --bin edb
target/release/edb --version
```

For library use, add `edb-core = { path = "/path/to/EDB" }` to your application's
dependencies. This release provides source archives; it does not include
prebuilt binaries or a crates.io package.

Follow [setup](../00_start_here/01_setup.md) for persistent storage and
[the in-memory tutorial](../01_tutorials/02_in_memory.md) to explore without a
PostgreSQL service.

## Compatibility and limitations

This release is experimental. API and storage formats may change. Earlier
development databases require fresh storage; there is no old-format migration
or downgrade tool. Use matching peer and transactor source revisions.

Historical reads depend on retention and excision. The current CLI and local
transport require Unix APIs; Windows is not supported, and other Unix platforms
have not been verified for this release.

See [release notices](../00_start_here/06_release_notices.md) for query and
entity-scan limitations and storage compatibility, and [operations](../08_operations/00_deployment.md)
for backup, restore, and deployment procedures.
